# Global E-Commerce Sales Analysis

## Project Overview

This project analyses more than 1 million retail transactions using MySQL.

The objective is to discover business insights related to:

- Revenue
- Customers
- Products
- Countries
- Sales Trends
- Returns
- Order Behaviour

Dataset Size:
- Records: 1,067,371
- Countries: 43
- Products: 5,132
- Registered Customers: 5,942
- Orders: 53,628

---

# Data Cleaning

Performed the following steps:

- Imported CSV into MySQL
- Converted InvoiceDate from TEXT to DATETIME
- Checked NULL values
- Checked Duplicate Records
- Removed unnecessary columns
- Verified data types
