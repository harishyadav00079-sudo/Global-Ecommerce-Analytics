# Global E-Commerce SQL Analysis

## Project Objective

Analyse over one million retail transactions using SQL to identify sales trends, customer behaviour, top-performing products, and business insights.

## Dataset

Global Online Retail Dataset (2009–2011)

Records: 1,067,371

Countries: 43

Customers: 5,942
